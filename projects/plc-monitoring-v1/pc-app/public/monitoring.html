④ 변수 목록그리드에서 영역·주소·타입 직접 입력, 허용오차·시작값·종료값·비교판정 관리

▲ 화면 전체 배치. ③과 ④ 사이 경계선을 드래그하면 폭을 조절할 수 있습니다.

1. 연결하기

CJ 시리즈 ▾1 PLC IP (예: 192.168.0.80)2 9600 UDP ▾3 연결4 연결 해제 연결됨
▲ 번호 순서대로: 시리즈 → IP(UDP/TCP만) → 연결 방식 → [연결].
  • 이 화면의 연결은 다른 화면(PLC 모니터링/변수 관리 그리드)과 완전히 독립입니다 — 기록을 시작해둔 채 다른 화면에 갔다 와도 계속 기록됩니다.
⚠️ USB만은 한 번에 한 화면만 쓸 수 있어서, 다른 화면에서 USB로 연결하면 이 화면의 USB 연결이 자동으로 끊깁니다. UDP/TCP는 세 화면 동시 연결이 가능합니다.

☑☑W10.5BOOL펌프 운전10
▲ 변수 목록은 "Recipes & Snapshots" 그리드와 같은 방식의 표(그리드 위젯)입니다. [+ 변수 추가]를 누르면 빈 행이 생기고, 영역/주소/타입 등 셀을 직접 클릭해서 입력합니다.
  • 표에서 영역 / 주소 / 타입 / 설명 / 허용오차(±)를 직접 입력할 수 있고, 차트 체크를 끄면 기록은 하되 그래프에는 표시하지 않습니다.
  • 비트 하나를 기록하려면 타입을 BOOL로 하고 주소를 10.5(워드.비트) 형식으로 입력합니다.
  • 선택 열은 [☑ 전체선택]/[☐ 전체해제]로 한 번에 켜고 끌 수 있고, 체크된 행만 [⚖ 비교판정] 대상이 됩니다.
  • [📥 비교값 불러오기]로 목록을 통째로 불러오고, [📊 비교값 내보내기]로 저장하며, [💾 변수 목록 저장]을 누르면 다음 접속 때 자동으로 불러옵니다.

  • 기록 주기는 실행 툴바의 폴링주기(ms)로 정합니다. 예: 1000 = 1초마다 한 번 기록.

  • 시작값·종료값을 기록한 뒤, 판정할 행을 체크하고 [⚖ 비교판정]을 누르면 그때 계산됩니다 — |시작값 − 종료값|이 허용오차(±) 이내면 OK, 벗어나면 NG로 각 행의 "비교판정" 열에 표시되고 결과 요약 창이 뜹니다(크기조절/이동 가능).
  • [🧹 초기화]를 누르면 시작값·종료값·비교판정 열만 지워집니다(다른 열은 그대로 유지).

4. 그래프 조작

개별 트렌드 Total 트렌드 Auto Fit Y min0 Y max100 Y Set 구간(초)60 X Set
▲ Total 트렌드 모드 — 모든 변수를 한 그래프에 겹쳐 표시. 마우스를 올리면 값 툴팁이 뜹니다.
  • 🖱 휠 확대/축소   🖱 좌클릭 드래그 이동(팬) 또는 영역 확대(마우스 모드에 따라)   🖱 우클릭 메뉴(전체보기/X·Y축/격자/PNG 저장)   🖱 호버 값 툴팁
  • 개별 트렌드 모드는 변수마다 작은 카드+그래프로 따로 보여주고, 카드를 클릭하면 그 변수만의 큰 팝업 그래프를 여러 개 동시에 띄울 수 있습니다.
  • 구간(초) + [X Set]: 지금 기준 최근 N초만 표시. 시작/종료 + [범위 설정]: 원하는 시각 구간을 직접 지정.
  • [Auto Fit]: Y축을 현재 데이터에 맞게 자동 조정. 수동으로 하려면 Y min/max 입력 후 [Y Set].
