구분 제공 스펙 및 혜택 특징 및 비용

웹 미리보기 임의 포트(3000 등) HTTPS 보안 터널링 외부 웹 브라우저에서 HMI 관제 화면 무료 확인

3. Cloud Shell 1분 자동 셋업

Google Cloud Shell 접속 후, 터미널에 아래 한 줄 명령어를 붙여넣으면 프로젝트 다운로드부터 서버 실행까지 자동 완료됩니다.

# 프로젝트 다운로드 및 HMI 모니터링 서버 원클릭 자동 실행 스크립트
cd ~ && git clone https://github.com/kang1976/virtual-company-os-hmi.git && \
cd virtual-company-os-hmi/projects/plc-monitoring-v1/pc-app && \
npm install && \
npm start
✅ 정상 실행 화면: 터미널 하단에 PLC 모니터링 서버 실행 중: http://localhost:3000 (0.0.0.0:3000) 문구가 뜨면 서버 구동이 100% 성공한 것입니다. (멈춘 것이 아니라 접속 대기 상태)

4. 웹 HMI 모니터링 화면 열기 (포트 3000)

1웹 미리보기 아이콘 클릭

터미널 우측 상단 도구 모음에서 웹 미리보기 (사각형 창 안에 돋보기/눈 모양 아이콘)을 클릭합니다.

2포트 변경 (Change Port) 선택

팝업 메뉴에서 포트 변경 (Change Port)을 선택하고 숫자 3000을 입력합니다.

3화면 확인

[변경 및 미리보기]를 누르면 새 탭에서 OMRON PLC HMI 제어 화면이 열립니다.

5. 에디터 계정 로그인 및 프로젝트 연결

Cloud Shell Editor에서 구글 계정 인증 및 프로젝트를 지정하는 명령어입니다.

# 1. 구글 클라우드 계정 로그인 인증
gcloud auth login

# 2. 구글 클라우드 프로젝트 지정 (Default Gemini Project)
gcloud config set project gen-lang-client-0386942686
⚠️ 팝업 차단 주의: 에디터의 Sign in 또는 Sign into cloud 클릭 시 반응이 없는 경우, 브라우저 상단 주소창 왼쪽의 자물쇠 아이콘 ➔ 팝업 및 리디렉션 ➔ [허용]으로 설정해야 합니다.

6. 클라우드 PC 끄기 (OFF) 및 세션 관리

종료 방법 명령어 / 동작 특징
터미널 명령어로 끄기 exit 가장 빠르고 깔끔하게 세션을 즉시 닫음
브라우저 닫기 브라우저 탭(X) 닫기 15~20분 뒤 자동으로 가상머신 절전/종료 전환
서버 프로세스만 멈추기 Ctrl + C 실행 중인 Node.js 서버만 중단하고 터미널 유지

7. 무료 잔여 시간 및 서버 상태(uptime) 확인

가상머신이 켜진 시간과 남은 용량을 터미널에서 즉시 조회할 수 있습니다.

# 가상머신 가동 시간 및 부하 확인
uptime
# 출력 예시: 09:47:37 up 1:14, 0 user, load average: 2.71, 1.00, 0.96
# ➔ [up 1:14] : 가상머신이 켜진 지 1시간 14분 되었다는 뜻

# 5GB 무료 영구 디스크 남은 용량 확인
df -h ~
⏱️ 주간 남은 무료 시간 확인: 구글 보안 정책상 주간 50시간 중 남은 시간은 터미널 명령어가 아닌, 화면 우측 상단 더보기(점 3개 ⋮) ➔ [사용량 (Usage)] 팝업창에서 직접 확인하실 수 있습니다.
