🗺 화면 한눈에 보기

이 화면은 자주 보는 변수들을 엑셀 같은 표(스프레드시트)로 관리하는 화면입니다. 변수 목록을 만들어두면 현재값이 실시간으로 갱신되고, 설정값 열로 PLC에 값을 쓸 수 있습니다.

③ 스프레드시트변수 목록 + 설명(G열) + 현재값(H열) + 설정값(I열) + 스냅샷/비교판정(J~L열). 엑셀처럼 자유롭게 편집

1. 연결하기

CJ 시리즈 ▾1 PLC IP (예: 192.168.0.80)2 9600 UDP ▾3 연결4 연결 해제 연결됨
▲ 번호 순서대로: 시리즈 → IP(UDP/TCP만, USB는 비워둠) → 연결 방식 → [연결].
  • 이 화면의 연결은 다른 화면(PLC 모니터링/트렌드 모니터링)과 완전히 독립이라 화면을 옮겨도 계속 통신합니다.
⚠️ USB만은 한 번에 한 화면만 쓸 수 있어서, 다른 화면에서 USB로 연결하면 이 화면의 USB 연결이 자동으로 끊깁니다. UDP/TCP는 세 화면 동시 연결이 가능합니다.

▲ 스프레드시트 구성 — B~F열에 변수를 정의하면 H열(현재값)이 실시간으로 갱신됩니다. G열은 자유 설명, J~L열은 스냅샷/비교판정 결과입니다(⑤절 참고).
  1. [➕ 변수추가]로 빈 행을 만들고, 셀을 클릭해 변수명 / 영역(D,H,W,CIO,E0..) / 주소 / 타입을 입력합니다.
  2. 비트 하나를 다루려면 타입 BOOL + 주소 100.5(워드.비트) 형식으로 입력합니다. STRING은 F열에 길이(워드 수)를 지정합니다.
  3. G열(설명·코멘트)에 이 변수가 무엇인지 자유롭게 메모할 수 있습니다.
  4. 여러 행을 지우려면 A열(선택)의 체크박스를 켠 뒤 [🗑 선택삭제]를 누릅니다. [☑ 전체선택]/[☐ 전체해제]로 모든 행을 한 번에 체크·해제할 수 있습니다.
  5. 여러 행의 타입을 한 번에 바꾸려면 "전체 타입 변경"에서 타입 선택 후 [일괄 적용].
  6. [➕ 열 추가]로 L열 뒤에 "비고" 같은 자유 입력 열을 추가할 수 있습니다.
💡 열 너비·행 높이 등 시트 서식을 조정한 뒤 [💾 변수목록저장]을 누르면, 다음에 불러올 때도 조정한 서식 그대로 복원됩니다.

5. 스냅샷 · 비교판정

지금 값을 "기준(Start)"과 "결과(End)"로 각각 스냅샷 찍어두고, 두 시점의 값이 그대로인지(OK) 달라졌는지(NG)를 한눈에 확인하는 기능입니다. 레시피 적용 전/후 비교, 설비 재기동 전/후 확인 같은 용도에 씁니다.

→
H(현재값) → J(Snap Start)복사 + 파일 저장
→
(레시피 적용 등
작업 수행)
→
📸 스냅샷② 다시 클릭 → "End" 선택
→
H(현재값) → K(Snap End)복사 + 파일 저장
▲ 스냅샷은 두 번 찍습니다 — 작업 전(Start)과 작업 후(End). 매번 파일로도 자동 저장됩니다(설정 페이지의 스냅샷 폴더).
  1. [📸 스냅샷]을 누르면 Start(J열)/End(K열) 중 어디로 복사할지 묻는 창이 뜹니다. 선택하면 그 순간의 H열(현재값)이 해당 열에 복사되고, 동시에 xlsx 파일로도 저장됩니다.
  2. 비교하고 싶은 변수만 A열(선택)에 체크한 뒤 [⚖ 비교판정]을 누릅니다.
  3. 체크된 행마다 J열과 K열 값을 비교해 완전히 같으면 OK, 다르면 NG(빨간 글씨)를 L열(비교판정)에 표시합니다.
  4. 결과 팝업에 비교 항목 수 / 일치율(%) / OK 개수 / NG 개수와 NG 항목 목록(설명 포함)이 표시됩니다.
  5. 팝업의 [📊 리포트 Excel 저장] / [📄 리포트 PDF 저장]으로 비교 결과를 파일로 남길 수 있습니다(저장 위치를 직접 고르는 창이 뜹니다 - Chrome/Edge 기준).
  6. 결과 창 상단(제목 부분)을 드래그하면 원하는 위치로 옮길 수 있고, 오른쪽 아래 모서리를 드래그하면 크기를 조절할 수 있습니다.
  7. [🧹 스냅샷 초기화](📸 스냅샷 버튼 오른쪽)를 누르면 Snapshots(Start)·Snapshots(End)·비교판정(J~L열) 내용을 모두 지우고 새로 시작할 수 있습니다.
⚠️ 비교판정은 완전히 일치할 때만 OK입니다. REAL(부동소수점) 타입은 아주 작은 오차만 있어도 NG로 표시될 수 있습니다.

6. 저장 · 변수 불러오기/내보내기

💾 변수목록저장1 📥 변수 불러오기2 📊 변수 내보내기3 📄 PDF 내보내기
  1. [💾 변수목록저장] — 지금 시트의 변수 목록(+열 너비 등 서식)을 서버에 저장합니다. 다음에 접속하면 자동으로 불러옵니다. 편집 후 저장을 잊지 마세요.
  2. [📥 변수 불러오기] — xlsx뿐 아니라 xlsm·xlsb·xls·csv 파일에서도 변수 목록을 통째로 읽어올 수 있습니다. [📊 변수 내보내기]로 만든 파일을 그대로 다시 불러올 수 있습니다.
  3. [📊 변수 내보내기] / [📄 PDF 내보내기] — 현재 목록 + 현재값(+설명)을 파일로 저장합니다(레시피 기록, 결과 보고용). Chrome/Edge에서는 저장 위치를 직접 고르는 창이 뜨고, 그 외 브라우저는 다운로드 폴더로 저장됩니다. 파일명: 접두사_Recipe_타임스탬프.xlsx(접두사는 설정 페이지에서 지정).
