이 화면은 PLC 메모리(D/H/W/CIO/EM)를 영역째로 훑어보는 "메모리 탐색기"입니다. 위에서부터 아래 순서로 배치되어 있습니다.

① 헤더❓ 사용법 · 테마 선택 · 다른 화면(그리드/트렌드)으로 이동하는 탭
② 연결 툴바PLC 시리즈/IP/방식 선택 → 연결 · 연결 상태 · 통신 카운터(SEND/RECV/에러/지연)
③ 폴링 툴바폴링주기(ms) · ▶ 시작 / ⏸ 일시정지 / ⏹ 정지 — 연결만으로는 읽기 시작 안 함
④ 메모리 영역 탭D · H · W · CIO · E0 ~ En 중 보고 싶은 영역 선택 (영역마다 설정을 독립적으로 기억)
⑤ 조회 설정시작 주소 · 페이지 크기 · 데이터 타입 · ✅ 값 적용(쓰기) · 전체 채우기 · 📊 내보내기
⑥ 실시간 값 그리드▶시작을 눌러야 값이 채워짐. 이후 주기마다 갱신 (값이 바뀌면 초록색 반짝임)
⑦ 쓰기 테스트 · PLC 에러 로그우측 패널
⑧ 통신 이력FINS 프로토콜 SEND/RECV 원문(hex) 확인
▲ 화면 전체 배치. 아래 각 절에서 번호 순서대로 자세히 설명합니다.

1. 연결하기

CJ 시리즈 ▾1 PLC IP (예: 192.168.0.80)2 96003 USB ▾4 연결5 연결 해제 연결됨6
▲ 화면 상단의 연결 툴바. 번호 순서대로 설정하고 [연결]을 누릅니다.
  1. PLC 시리즈 선택 — 보통은 CJ 시리즈를 그대로 둡니다. (NX 시리즈는 7절 참고)
  2. PLC IP 주소 입력 — UDP/TCP로 연결할 때만 필요합니다. USB는 비워둬도 됩니다.
  3. 포트 — 기본값 9600을 그대로 두면 됩니다.
  4. 연결 방식 선택 — 아래 표를 참고하세요.
  5. [연결] 클릭 — 성공하면 헤더에 CPU 모델명(예: CJ2H-CPU65-EIP)이 표시됩니다.
  6. 상태 표시가 초록색 "연결됨"으로 바뀌면 완료. 끝낼 때는 [연결 해제]를 누릅니다.
방식입력할 것이런 경우에 사용
USB없음 (케이블만 연결)PC와 PLC를 USB 케이블로 직접 연결. 최초 1회 WinUSB 드라이버 설치 필요
UDPIP 주소, 포트(9600)같은 공장 네트워크(LAN)에서 가장 간단하고 빠른 방식
TCPIP 주소, 포트(9600)공유기 경유 등 안정적인 연결 유지가 필요할 때
⚠️ 세 화면(PLC 모니터링/변수 관리 그리드/트렌드 모니터링)은 각자 독립된 연결을 가지므로 화면을 옮겨도 통신이 계속됩니다. 단 USB만은 한 번에 한 화면만 쓸 수 있어서, 다른 화면에서 USB로 연결하면 이 화면의 USB 연결이 자동으로 끊깁니다. (UDP/TCP는 세 화면 동시 연결 가능)

▲ 폴링 툴바 → 영역 탭 → 조회 설정 → 실시간 값 그리드. 방금 값이 바뀐 칸은 초록색으로 반짝입니다(D1).
  1. 폴링주기(ms)를 정하고 [▶ 시작]을 눌러야 값 읽기가 시작됩니다. 연결만 해서는 값이 자동으로 채워지지 않습니다. [⏸ 일시정지]로 잠시 멈추고 [▶ 시작]으로 이어서 재개하거나, [⏹ 정지]로 완전히 멈출 수 있습니다.
  2. 보고 싶은 메모리 영역 탭을 클릭합니다. EM 뱅크(E0~En) 개수는 연결된 CPU 모델에 맞춰 자동으로 조정됩니다.
  3. 시작 주소를 입력하거나 ◀ ▶ 버튼으로 페이지를 넘깁니다.
  4. 데이터 타입을 고릅니다 — WORD(기본), INT, DINT, REAL, STRING 등. BOOL을 고르면 각 워드가 16개 비트 표로 펼쳐져 비트별 ON/OFF가 보입니다.
💡 시작 주소·페이지 크기·데이터 타입은 영역별로 따로 기억됩니다. D 영역에서 설정을 바꾸고 W 영역으로 갔다가 다시 D로 돌아와도, D에서 마지막에 쓰던 설정 그대로 복원됩니다(다른 화면에 갔다 와도 유지).

▲ 쓰기 순서. 여러 칸을 한꺼번에 수정한 뒤 한 번에 적용할 수도 있습니다.
  • BOOL 표시 모드에서는 비트 칸을 클릭해서 ON/OFF를 바꾼 뒤 같은 방법으로 적용합니다. 해당 비트만 바뀌고 같은 워드의 다른 비트는 보존됩니다.
  • 우측 "쓰기 테스트" 패널에서는 영역/주소/값을 직접 지정해서 한 워드씩 쓸 수도 있습니다.
  • [전체 채우기] — 왼쪽 입력칸에 값(예: 0)을 넣고 누르면, 현재 화면에 보이는 모든 칸의 설정값이 그 값으로 한꺼번에 채워집니다. 이때는 아직 PLC에 쓰지 않은 상태이니, 채워진 값을 확인한 뒤 [✅ 값 적용(쓰기)]을 눌러야 실제로 반영됩니다.
⚠️ 실제 설비가 움직이는 PLC에 쓰기 전에, 영향 없는 W 영역 주소로 먼저 테스트하는 것을 권장합니다. [전체 채우기]는 화면에 보이는 범위(페이지 크기) 전체를 한 번에 바꾸는 기능이라 더욱 주의하세요.

5. 에러 로그 · 통신 이력

SEND읽기 요청 (128개 항목, SID=42) 80 00 02 00 50 00 …
RECV응답 수신 (SID=42)
ERROR[D] TCP 응답 타임아웃 (SID=43)
▲ 화면 하단 "통신 이력"의 예 — 파란색 SEND(보냄) / 초록색 RECV(받음) / 빨간색 ERROR(오류).
  • 통신 이력(하단 좌측): PLC와 실제로 주고받은 FINS 프로토콜 내용을 원문(hex)까지 보여줍니다. [에러만 보기]로 오류만 필터링하고, [초기화]로 지울 수 있습니다.
  • PLC 에러 로그(하단 우측): [조회] 버튼을 누르면 PLC CPU 내부에 저장된 에러 이력(발생 시각·에러 코드·설명)을 읽어옵니다. 통신 오류가 아니라 PLC 자체의 이상 이력을 확인하는 기능입니다.

6. 지연시간 트렌드

SEND: 1204 RECV 성공: 1198 에러: 6 지연: 12ms ← 클릭1
  • 상단 카운터의 "지연" 숫자를 클릭하면 최근 응답 지연시간(왕복 시간)을 선 그래프로 보여주는 팝업이 뜹니다. 통신이 느려지는 순간을 눈으로 확인할 때 사용합니다.
  • 팝업 제목줄을 드래그하면 위치를 옮길 수 있고, ▶ 시작/⏸ 일시정지/⏹ 정지로 기록을 제어합니다.
