## 2. 갤럭시 Z 폴드5 (`SM-F946N`) 설치 및 사용 방법

### 2.1 APK 파일 폰으로 전송
1. PC와 갤럭시 Z 폴드5를 **USB 케이블로 연결** (또는 카카오톡 '나와의 채팅' / 샌드 애니웨어 / 구글 드라이브 이용).
2. 생성된 **`Omron_CJ2H_Direct_Monitor.apk`** 파일을 폰의 `다운로드(Download)` 폴더로 복사합니다.

### 2.2 스마트폰에서 앱 설치
1. 갤럭시 폰의 **[내 파일]** 앱 실행 $\rightarrow$ **[설치 파일(APK)]** 또는 **[다운로드]** 터치.
2. `Omron_CJ2H_Direct_Monitor.apk` 터치 후 **[설치]** 진행.
   * *(출처를 알 수 없는 앱 설치 허용 팝업 시 '허용' 선택)*

### 2.3 현장 사용 방법 (같은 Wi-Fi 연결 필수)
1. 스마트폰이 PLC와 동일한 **iptime Wi-Fi**에 연결되어 있는지 확인.
2. 앱 실행 후 기본 입력값 확인:
   * **PLC IP**: `192.168.0.80` / **Port**: `9600`
   * **PLC 노드 (DA1)**: `80`
   * **폰 노드 (SA1)**: `15` (스마트폰의 Wi-Fi IP 끝자리)
3. **[접속 테스트]** 또는 **[실시간 모니터링]** 터치 $\rightarrow$ **PLC와 직접 1:1 통신 시작!**
4. Z 폴드5를 **펼치면 2단 와이드 모니터링 화면**, **접으면 1단 심플 모드**로 자동 전환됩니다.
