## 2. 타겟 디바이스(Z 폴드5) 해상도 및 반응형 UI 설계 스펙

* **기종명**: 삼성 갤럭시 Z 폴드5 (`SM-F946N`)

```
+---------------------------+       +---------------------------------------------+
|    [1] 커버 화면 (접힘)    |       |             [2] 메인 화면 (펼침)             |
|                           |       |                                             |
|  해상도: 2316 x 904 px    |  -->  |  해상도: 2176 x 1812 px                     |
|  화면비: 23.1 : 9 (세로)  |       |  화면비: 21.6 : 18 (정사각형에 가까운 와이드)|
|                           |       |                                             |
|  [ 1열 카드/리스트 뷰 ]    |       |  [ 좌: 설정/제어판  |  우: 데이터 테이블/차트 ] |
+---------------------------+       +---------------------------------------------+
```

### 반응형 분기 기준 (Responsive Breakpoint)
* 화면 폭(`MediaQuery.size.width`)이 **600dp 미만**: **커버 모드 (1열 단일 뷰)**
* 화면 폭(`MediaQuery.size.width`)이 **600dp 이상**: **메인 모드 (2열 분할 와이드 뷰)**
