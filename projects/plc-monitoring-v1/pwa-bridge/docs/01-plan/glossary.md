# 용어집 (Glossary) — 모바일/태블릿 PLC 원격 제어

> **작성일**: 2026-08-26
> **목적**: 이 프로젝트 전반에서 일관되게 쓸 용어를 한글 표현 ↔ 기술 표준 용어로 매핑

---

## 도메인 용어

| 한글 표현 | 기술 용어 | 설명 |
|---|---|---|
| PLC | Device | 제어 대상 장비. 1차 범위: Omron CJ 시리즈(CJ1/CJ2) 1대 |
| 태그 / 메모리 포인트 | Tag | PLC 메모리 주소(CIO/D/W 등)에 매핑되는 논리적 이름. 예: `PUMP1_RUN` → `CIO0000.00` |
| 통신 프로토콜 | FINS | Omron PLC 전용 통신 프로토콜 (FINS/TCP, FINS/UDP) |
| 브릿지 서버 | Bridge Server | 모바일 앱(HTTP/WebSocket) ↔ PLC(FINS) 사이를 중계하는 백엔드 서버. 인증/인가/오조작 방지 로직이 위치하는 핵심 계층 |
| 조작 | Command | 사용자가 특정 Tag에 값을 쓰는 요청 (예: 기동/정지, 설정값 변경) |
| 전면 제어 | Full Control | 관리자(ADMIN) 등급이 가진 권한 — 모든 Tag 읽기/쓰기 가능 |
| 오조작 방지 | Miss-operation Prevention | 위험 Command에 대한 2단계 확인, 이력 기록 등 안전장치 |
| 접속 세션 | Session | 모바일/태블릿 클라이언트의 로그인~로그아웃 구간 |
| 조작 이력 | Audit Log | 모든 Command/로그인/로그아웃 이벤트의 기록 |
| 경보 / 상태값 | Alarm / Status | PLC에서 읽어오는 이상 상태 또는 현재 상태값 |

---

## 권한 등급 (3단계)

| 등급 | 코드 | 권한 범위 |
|---|---|---|
| 관리자 | `ADMIN` | 전면 제어 — 모든 Tag 읽기/쓰기, 위험 Command 포함 |
| 운영자 | `OPERATOR` | 제한적 조작 — 화이트리스트로 지정된 Tag만 쓰기 가능, 위험 Command 불가 |
| 조회자 | `VIEWER` | 읽기 전용 — 모니터링만 가능, 쓰기 불가 |

> 위험 Command(예: 기동/정지, 강제 출력 등)의 구체적 목록은 **아직 미확정** — 설계 단계(`docs/02-design/`)에서 현장 담당자 확인 후 반드시 채워야 함. 안전과 직결되므로 추정으로 정의하지 않음.

---

## 통신 관련 약어

| 약어 | 의미 |
|---|---|
| FINS | Factory Interface Network Service (Omron 전용 프로토콜) |
| CIO | Core I/O 영역 (Omron 메모리 영역 중 하나) |
| D | Data Memory 영역 |
| W | Work 영역 |

> CJ 시리즈 실제 메모리맵(CIO/D/W 상세 주소)은 아직 문서화되어 있지 않음 → `schema.md`에는 **최소 예시 태그**만 우선 정의하고, 실제 배선/PLC 프로그램 확인 후 확정 예정.
