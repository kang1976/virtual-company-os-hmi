## 1. 시스템 요구사양
- OS: Windows 10/11 64-bit, Ubuntu 22.04 LTS 이상
- CPU: Quad-Core 2.5GHz 이상 / RAM: 8GB 이상
- 네트워크: 100Mbps Ethernet 이상 (PLC 제어망 분리 권장)
- 브라우저: Chrome 100+, Edge 최신버전 (모바일 브라우저 완벽 호환)

---

## 2. 빠른 시작 (Quick Start)
1. [서버 구동]: `uvicorn backend.app.main:app --port 8000` 실행
2. [클라이언트 접속]: 브라우저에서 `http://localhost:5173` 접속
3. [PLC 연동 확인]: 상단 실시간 WS 인디케이터 초록불 확인 후 지시 하달

---

## 3. 화면별 UI 조작 가이드
- **전체 관제실 (Overview)**: 상단 핵심 KPI 4종(누적태스크, 마감수, 진행수, FTO통과율) 및 실시간 이벤트 티커 모니터링
- **5단계 칸반 (Kanban)**: IDLE -> WORKING -> SUBMITTED -> REVIEW -> VERIFIED 5단계 공정 추적 및 카드 클릭 시 4단계 심층 내역 열람
- **4대 장부 (Ledgers)**: 지시·업무·회의·특허·마케팅 원장을 마크다운/JSON으로 즉시 열람 및 원클릭 복사
- **가상 조직도 (Org)**: 10대 전문 에이전트 실시간 가동 상태 및 상세 직무 점검

---

## 4. 산업용 PLC 통신 연동 가이드
1. 대상 PLC(Omron CJ/CS/NJ/NX 시리즈)의 FINS 노드 번호 및 IP 대역 확인 (기본: 192.168.250.1)
2. UDP 포트 9600 개방 및 방화벽 인바운드 규칙 등록
3. 데이터 메모리(DM/CIO) 읽기/쓰기 권한 및 헤더 시퀀스 동기화 설정

---

## 5. 긴급 장애 조치 및 FAQ (Troubleshooting)
- **Q1. WebSocket 연결이 '연결중'에서 멈춥니다.**
  -> 백엔드 8000 포트 프로세스가 정상 구동 중인지 점검하십시오.
- **Q2. 라이트/다크 테마 전환 시 화면이 깜빡입니다.**
  -> GPU 가속 설정 및 브라우저 캐시를 새로고침(Ctrl+F5)하십시오.
- **Q3. PLC 데이터 패킷 손실이 발생합니다.**
  -> 산업용 제어망 스위치 허브의 패킷 큐와 듀플렉스(Full-Duplex) 설정을 확인하십시오.
