## 2. 4대 핵심 지시사항 구현 내역

### 1) 배관 계통별 명확한 색상 규격화 (Color Coding)
국제 ISA-5.1 및 고성능 SCADA HMI 규격에 맞추어 4대 배관 라인을 엄격히 색상 분리 및 이중 네온 글로우로 렌더링하였습니다.

| 배관 계통 | 규격화 색상 | HEX 코드 | 배관 기능 및 용도 |
| :--- | :---: | :---: | :--- |
| **메인 가스 라인** | **네온 시안** | `#00F0FF` | 실린더 A/B ➔ 레귤레이터 ➔ 메인 공정 챔버 주공급 |
| **퍼지/질소(N2) 라인** | **에메랄드 그린** | `#10B981` | N2 Supply ➔ 매니폴드 잔류 가스 치환 및 세정 |
| **진공/배기(Vent) 라인**| **앰버 오렌지** | `#F59E0B` | 공정/퍼지 가스 외부 Scrubber 및 Vent Stack 배출 |
| **알람/비상(EMG) 라인** | **루비 레드** | `#EF4444` | 이상 고압/누출 시 긴급 차단 및 릴리프(Relief) 안전 배출 |

### 2) 배관 라인 흐름 방향 표시 (정적 화살표 + 미세 흐름 애니메이션)
- **정적 방향 화살표 (`▶`)**: 배관 구간마다 60px 간격으로 유동 방향을 표시하여 정지 상태에서도 가스 흐름 경로 확인 가능.
- **실시간 미세 흐름 애니메이션**:
  - `AnimationController` 기반의 부드러운 60fps 흐름 파티클 엔진 탑재.
  - 열려 있는 공급 경로(Cylinder ➔ AV1 ➔ REG ➔ AV2 ➔ Main Valve ➔ Process)를 따라 밝은 발광 입자가 이동하여 **현재 가스가 공급되고 있는 배관을 즉시 식별**.
  - 상단 툴바의 **[흐름 ON / OFF]** 토글 스위치로 사용자가 원할 때 즉시 애니메이션 전환 가능.

### 3) 밸브 상태의 2단계 시각화 (ISA-5.1 2-Stage Visualization)
산업 표준 나비넥타이(Bowtie ⧓) 심볼을 기반으로 열림과 닫힘을 뚜렷이 대비시켰습니다.

- **열림 (Open)**:
  - 밸브 내부 **전체 채움(Fill) + 밝은 에메랄드 녹색/네온 시안**
  - 외곽 반투명 글로우 오라(Glow Aura) + `[OPEN]` 녹색 뱃지
- **닫힘 (Closed)**:
  - 밸브 내부 어두운 배경 + **외곽 테두리선만 표시(Outline) + 딥그레이 (`#64748B`)**
  - 회색 액추에이터 + `[CLOSED]` 그레이 뱃지
- **터치 인터랙션**:
  - 모바일 화면에서 특정 밸브를 터치하면 해당 밸브의 **상세 정보/PLC 태그 주소(예: `CYL_A.Valve_AV1`)** 와 **열기/닫기 제어 다이얼로그**가 팝업되어 직접 테스트 가능.

### 4) 센서 (PT, TT, FM, WG) 박스 칩 배치 (Monospace 고대비 폰트)
- 배관 라인 노드 바로 위/옆에 **고대비 칩 형태 (`#060D1A` 배경 + 컬러 테두리)** 로 배치.
- 센서 ID (`PT1A`, `PT2A`, `FM1`, `TT1`, `WG1A` 등)와 실시간 측정값 (`45.8 bar`, `320.0 L/m`, `23.8 °C`)을 **Monospace 고정폭 폰트**로 렌더링하여 수치 판독성 극대화.

### 5) 모바일 터치 및 인터랙티브 탐색 (`InteractiveViewer`)
- 스마트폰 화면(360~430px)에서도 자유롭게 **두 손가락 핀치 줌(0.5x ~ 3.5x)** 및 **한 손가락 드래그 탐색(Pan)** 지원.
- 상단 툴바에 **[1:1 화면 맞춤]** 리셋 버튼 탑재.
- 퀵 모드 프리셋 버튼 제공:
  - `[Side A 공급]`: AV1A, AV2A, AV3A, V_MAIN 열림
  - `[Side B 공급]`: AV1B, AV2B, AV3B, V_MAIN 열림
  - `[N2 퍼지]`: V_N2A, V_N2B, V_VENT_A, V_VENT_B 열림
  - `[비상 차단]`: 주공급 밸브 전체 차단, V_EMG 릴리프 열림
